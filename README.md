# 写作词间

为学术英语报告写作准备的本地背词应用。词库包含1000个不重复的英文单词，分为20个主题，150个核心词优先服务于描述型、分类型和组成型报告。词表按课程主题与常用学术表达整理，并非老师公布的考试指定词表。

## 打开使用

最方便的方式：双击 output 文件夹中的「写作词间_1000词.html」，使用 Chrome、Edge 或 Safari 打开。它是完整的单文件应用，不需要安装或联网。

也可以双击本文件夹中的 index.html。该文件需要与 vocabulary.js、pronunciation.js、core.js、writing-guide.js、writing-guide-ui.js、app.js、styles.css 保持在同一个文件夹内。

## 每日学习与反复巩固

- 默认每日150个不同新词，使用完整1000词范围，核心150词优先。旧版本自动更新此学习计划，保留考试日期、单词记录、草稿与统计；此后可在设置中自定义数量与范围。
- 每个词先判断认识／不确定／不认识，再检测拼写。不确定或不认识时先学释义、搭配和例句。拼写时隐藏英文、音标、发音和例句。
- 不认识、不确定或首轮拼写错误：加入巩固队列，隔最多3个词再次出现。必须连续两次“认识且首轮拼对”才能结束巩固，期间失败则重新要求两次通过。
- 看答案后马上重试拼对不算独立通过；首轮失败保留。只剩一个巩固词时会直接再次出现。
- 保存检测后可以随时退出或刷新，剩余巩固次数仍保存，点击“继续巩固”恢复。
- 重复练习不增加不同新词数。当天复习词按不同词统计，检测次数另外累计。图表按每天不同单词去重。

## 分类复习

- 认词问题：曾经“不认识”或“不确定”。
- 拼写问题：曾经首轮拼错或不会拼写。
- 同一个词可以属于两组；正确回答不会覆盖历史问题。两组、全部难词均可每天反复复习，也可练所有已学词。
- 可按词义搜索、主题和状态筛选，再点击“复习当前筛选结果”。
- 旧版未保存足够错误类型的历史记录列为“旧记录类型不明”，不会猜测它是认词还是拼写问题。重新检测会留下明确分类。
- 新版增加可选历史分类与巩固次数，保持原备份版本及存储键兼容；非法分类或巩固数据会阻止导入。
- 长期间隔数据保留；当天反复正确不会连续跳过多个记忆阶段。复习入口可随时进入，不要求等待到期。

## 记录与备份

记录保存于当前浏览器的本机存储，不上传，不需要账户。建议每天导出学习备份。换设备、换浏览器、清理浏览器数据或改用另一个入口时，需要导入备份。

本地HTML入口和本地网页入口各自保存记录。选定一个固定入口持续使用，切换时使用「导出／导入备份」。

导入会先检查格式，再请求确认替换当前记录。词汇备份包含学习设置、单词记录与每日统计，不包含写作草稿。草稿可以在写作练习页面下载成文字文件。

每个词提供英式与美式 IPA 音标，以及正常、慢速发音按钮。音标随应用保存，可离线查看。在线发音使用有道词典音频，失败后尝试设备的英文语音。多读音词优先用简短语境朗读，以匹配当前词性。音频与设备语音都不可用时会显示提示。

认词、学习与查看结果页面均提供音标与发音。进入拼写检测时停止播放，隐藏音标、发音按钮和英文答案。读音中的 ˈ 表示主重音，ˌ 表示次重音。

IPA数据来源与许可证详见 pronunciation-sources.md 与 licenses/。

## 词库说明

所有词条含词性、中文释义、常用搭配和英文示例。核心150词另附例句中文译文。扩展词的例句主要用于演示搭配，学习后应尝试换成自己的写作主题。优先记搭配、检查拼写，再将词用于短报告。

## 报告模版与写作练习

「写作练习」上方提供详细的中文使用指南，基于第三课报告写作资料整理：六步拆题、特征/类别/部分的判断、共用12句框架、三种扩展模版、逐句作用、填空示范、三篇150—200词范文及中文解释、词数增删方法和表达句库。

切换题型不会改动草稿。可复制模版，或在练习区为空时直接放入；已有草稿时保留内容。指南可以下载为 Markdown 文档，离线单文件版也可下载。Word 版在 output/三种Report模版使用文档.docx。

课程提出避免连续复制7词，因此资料强调背结构与短语、按题目重新组织表达，不将示范稿直接作为提交稿。考试字数和标注方式以实际题面为准。

- writing-guide.js：详细写作指南、共用框架、模版和文档内容
- writing-guide-ui.js：指南与模版界面
- 三种Report模版使用文档.md：可单独阅读的详细文档

## 前三课语法与雷点

写作练习顶部新增前三课语法复习，标明课次与PPT页码，包含16项语法检查点、7项文体雷点、第一课来源与诚信要求、综合改写和交卷清单。区分语法错误与文体偏好，避免把第一人称、there be、被动语态或名词化当成一律禁止。可单独下载；完整模版使用文档也附有该部分。

## 拼写结果对照

正确答案在上，输入在下逐字对齐。绿色突出应写字母，红色标出错写与漏写（□），橙色标出多写；正确部分保留普通样式。字母大小写按已有拼写检测规则忽略。重试后可展开首轮错误输入，首次失败仍保留。超长输入直接完整显示，不运行逐字匹配；移动端长对照可在卡片内左右滑动。
